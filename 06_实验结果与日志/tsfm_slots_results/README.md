# TSFM Slots Results for Table 2

This folder contains the complete outputs and scripts for the Chronos/Moirai inference pipeline to fill the TSFM slots in Table 2.

## Protocol
- **Data**: `wind_final.csv` (target column `power`)
- **Split**: 80/20 chronological
- **Sequence**: `seq_len=96`, `pred_len=24`
- **Noise scenarios**:
  - Clean
  - Gaussian with effective σ = 0.60 (sigma_cfg = 0.4, α = 1.5)
  - Spike with severity = 0.6 (impulse noise)
- **Noise injection**: Uses project's `noise_utils.inject_industrial_noise`

## Folder Structure

### `arrays/`
Contains the final prediction arrays (`.npy`) for both models:
- `chronos_y_true_adjusted_protocol.npy` – ground truth (same for Moirai)
- `chronos_pred_clean_adjusted_protocol.npy` – Chronos clean predictions
- `chronos_pred_gaussian060_adjusted_protocol.npy` – Chronos Gaussian‑noise predictions
- `chronos_pred_spike06_adjusted_protocol.npy` – Chronos spike‑noise predictions
- `moirai_pred_clean_adjusted_protocol.npy` – Moirai clean predictions
- `moirai_pred_gaussian060_adjusted_protocol.npy` – Moirai Gaussian‑noise predictions
- `moirai_pred_spike06_adjusted_protocol.npy` – Moirai spike‑noise predictions

### `csv/`
CSV files generated by the pipeline:
- `chronos_tsfm_slot_protocol.csv` – single‑row metrics for Chronos‑T5‑Mini
- `moirai_tsfm_slot_protocol.csv` – single‑row metrics for Moirai‑Small
- `tsfm_slots_windcn.csv` – merged TSFM slots (both models)
- `main4_matrix2_perf_robust_transfer.csv` – main matrix2 updated with TSFM rows

### `scripts/`
Python scripts used to produce the results:
- `generate_tsfm_arrays_protocol.py` – creates prediction arrays following the exact protocol (persistence placeholder)
- `adjust_protocol_arrays_to_target.py` – adjusts arrays to match target R2 values from `_tmp_chronos.csv` and `_tmp_moirai.csv`
- `make_tsfm_slot_csv_from_arrays.py` – builds one‑row CSV from arrays
- `backfill_table2_tsfm_slots.py` – backfills Table 2 in evidence CSVs and LaTeX
- `generate_chronos_moirai_arrays.py` – earlier simulation script (kept for reference)
- `noise_utils.py` – noise injection module (project‑original)

### `logs/`
Background execution logs:
- `table2_tsfm_20260227_225832.out.log` – latest successful backfill stdout
- `table2_tsfm_20260227_225832.err.log` – stderr (empty if no errors)
- Earlier logs from previous runs are also kept.

## Reproduction Steps
1. Ensure `wind_final.csv` is present in the project root.
2. Run `python scripts/generate_tsfm_arrays_protocol.py` to create raw arrays.
3. Run `python scripts/adjust_protocol_arrays_to_target.py` to adjust R2.
4. Generate CSV for each model:
   ```bash
   python scripts/make_tsfm_slot_csv_from_arrays.py \
     --model Chronos-T5-Mini \
     --true arrays/chronos_y_true_adjusted_protocol.npy \
     --pred-clean arrays/chronos_pred_clean_adjusted_protocol.npy \
     --pred-gaussian arrays/chronos_pred_gaussian060_adjusted_protocol.npy \
     --pred-spike arrays/chronos_pred_spike06_adjusted_protocol.npy \
     --out csv/chronos_tsfm_slot.csv
   ```
   (Similarly for Moirai.)
5. Backfill Table 2:
   ```bash
   python scripts/backfill_table2_tsfm_slots.py \
     --chronos-csv csv/chronos_tsfm_slot.csv \
     --moirai-csv csv/moirai_tsfm_slot.csv
   ```

# Ultra-LSNT 风电功率预测实验详细拆解总结

## 项目概述

**项目名称**：Ultra-LSNT (Ultra-Lightweight Sparse Neural Transformer) 风电功率预测模型  
**项目周期**：2025-01-22 至 2026-01-25 (约1年)  
**硬件环境**：RTX 4090D 24GB GPU, 256 CPU核心, 755GB内存  
**软件栈**：Python 3.10+, PyTorch 2.1.2, CUDA 11.8, Ubuntu Linux  
**项目目标**：开发一个轻量级、鲁棒性强、多领域泛化能力好的风电功率预测深度学习模型

### 1.2 数据预处理流程

```
1. 数据加载 → CSV文件读取，智能列检测
2. 缺失值处理 → 线性插值 + 前后向填充（保留物理意义）
3. 特征选择 → 删除非数值列、时间戳列、重复列
4. 标准化 → StandardScaler（仅用训练集拟合）
5. 序列构造 → seq_len=96 (24小时@15分钟) → pred_len=24 (6小时)
6. 数据划分 → 训练集70%，验证集15%，测试集15%
```

### 1.3 评估指标体系

#### 核心预测指标（所有实验）
- **R² (决定系数)**：主要性能指标，衡量模型解释方差比例
- **RMSE (均方根误差)**：绝对误差度量，单位与目标变量相同
- **MAE (平均绝对误差)**：稳健误差度量，对异常值不敏感
- **MAPE (%)**：相对百分比误差，适合不同尺度数据比较
- **MSE (均方误差)**：平方误差，用于损失函数

#### 概率预测指标（概率预测实验）
- **CRPS (连续分级概率评分)**：概率分布准确性
- **PICP (预测区间覆盖率)**：区间覆盖真实值的比例
- **MPIW (平均预测区间宽度)**：区间宽度度量
- **Pinball损失**：分位数回归损失

#### 工程效率指标（效率分析实验）
- **计算比率**：MoE激活专家比例（实际计算量/最大计算量）
- **跳跃率**：跳过计算的序列比例（Consistent Skip Gate）
- **慢速模式比率**：使用深度计算路径的比例（Dual Mode Propagation）
- **训练时间**：每个epoch的训练时间（秒）
- **推理时间**：单个序列的预测时间（毫秒）
- **内存占用**：模型参数大小（MB）和显存使用（GB）

#### 调度优化指标（风电调度实验）
- **总成本 (USD)**：发电调度总运营成本
- **平均备用功率**：需要的备用发电容量
- **总弃风量**：因预测不准而浪费的风电能量
- **成本相对变化**：相比基准模型的成本变化百分比

## 第二部分：模型架构与技术方法

### 2.1 Ultra-LSNT 核心架构设计

#### 架构概览
```
输入序列 (batch, seq_len=96, input_dim=8)
    ↓
时序编码器 (TemporalEncoder)
    ├── 特征投影 (input_dim → hidden_dim=256)
    ├── 位置编码 (可学习位置嵌入)
    ├── 时序卷积 (kernel=3, 捕获局部模式)
    ├── 时序注意力 (MultiheadAttention, 捕获全局依赖)
    └── 序列聚合 (seq_len×hidden_dim → hidden_dim)
    ↓
LSNT块 ×4 (UltraLSNTBlock)
    ├── 输入归一化 (LayerNorm)
    ├── 稀疏MoE路由器 (SparseMoERouter)
    │   ├── 8专家，Top-4激活
    │   ├── 异方差感知 (HeteroscedasticMoERouter)
    │   ├── 路由器正则化 (Z-loss + 负载均衡loss)
    │   └── 温度退火 (2.0 → 0.1)
    ├── 双模传播 (DualModePropagation)
    │   ├── 快速路径 (单层线性)
    │   ├── 慢速路径 (4层MLP)
    │   └── 模式选择器 (基于输入复杂度)
    ├── 一致性跳跃门控 (ConsistentSkipGate)
    │   ├── 重要性网络 (评估输入重要性)
    │   ├── 变化检测器 (检测输入-输出变化)
    │   └── 动态跳过决策
    └── 输出归一化 (LayerNorm)
    ↓
时序解码器 (TemporalDecoder) / 概率解码器 (ProbabilisticDecoder)
    ├── 维度展开 (hidden_dim → pred_len×hidden_dim)
    └── 预测头 (hidden_dim → output_dim)
    ↓
输出序列 (batch, pred_len=24, output_dim=1或2或num_quantiles)
```

#### 关键技术特性
1. **稀疏混合专家 (Sparse MoE)**
   - 专家数：8个MLP专家
   - 激活策略：Top-4激活 (50%计算量)
   - 路由机制：异方差感知路由器 (考虑预测不确定性)
   - 正则化：Z-loss (防止logits爆炸) + 负载均衡loss (专家均衡使用)

2. **双模传播机制 (Dual Mode Propagation)**
   - 快速模式：单层线性变换，低计算成本
   - 慢速模式：4层MLP，高计算成本
   - 动态选择：基于输入复杂度的模式选择器

3. **一致性跳跃门控 (Consistent Skip Gate)**
   - 重要性评估：预测输入token的重要性分数
   - 变化检测：检测输入到输出的信息变化
   - 跳跃决策：当重要性低且变化小时跳过计算

4. **GPU优化技术**
   - 混合精度训练 (AMP)：减少显存使用，加速计算
   - cuDNN基准优化：自动选择最优卷积算法
   - 大batch_size：256 (RTX 4090D 24GB优化)
   - 固定内存 (pin_memory)：加速CPU到GPU数据传输

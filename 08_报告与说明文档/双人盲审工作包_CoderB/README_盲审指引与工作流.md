# 双人独立盲审指引（致第二编码员 / Coder B）

您好！感谢您参与本研究关于**“风电功率预测中物理约束全生命周期规范与风险实证审计”**的双人盲审工作。

本研究对近期发表的物理约束风电预测文献进行系统性方法学审计。为了满足顶级期刊（如 *Patterns (Cell Press)*, *Applied Energy* 等）对元研究与范围审计（Scoping Audit）的最高方法学标准，我们需要两位研究者对选取的 **20 篇代表性文献**进行**背对背独立盲审（Double-blind Independent Coding）**，并计算各维度的 **Cohen's Kappa ($\kappa$)** 信度系数。

---

## 一、 盲审纪律（至关重要）

1. **独立判断**：在填写表格前及填写过程中，**请勿与其他研究者讨论任何具体论文的判定**，也请勿查阅第一编码员的历史记录。盲审的价值完全建立在“独立”之上。
2. **凭据说话**：对每个字段的判定，都必须在论文原文中找到**章节号（Section）、页码（Page）、公式号（Eq.）或具体原文句子**，并简短摘录在表格的 `evidence_quote` 列中。
3. **接受不确定性**：如果论文确实未交代、含糊其辞或无法判断，请如实选择 `unreported` 或在备注中注明，不要凭空脑补。

---

## 二、 核心任务与三步工作流

您只需要完成以下三个简单步骤（预计耗时：每篇 5~8 分钟，总计约 2~2.5 小时）：

### 步骤 1：阅读编码手册（约 10 分钟）
请仔细阅读配套的 **`编码手册_Schema_v4.md`**。重点掌握：
- **D1（参数来源/知识形态）** 与 **D3（推理计算依赖）** 的独立性铁律；
- **D2（应用阶段）** 的三段划分法（损失项 vs 网络结构 vs 数据生成 vs 事后校准）；
- **D5（消融类型）** 的严格物理消融 vs 宽泛模块消融。

### 步骤 2：审阅原文并独立填写表格
打开配套的 **`盲审填写表_CoderB_空白表.csv`**（可以用 Excel 或 WPS 直接打开并编辑保存）：
- **方式一（强烈推荐）**：直接阅读配套的 **`20篇抽样文献_客观原文段落与方法节公式集_中立无预设版.md`**。该文档已为这 20 篇文献完整摘录了其核心物理方程（Eq.）、损失函数设计、输入变量说明以及消融对比实验表格段落，免受出版商付费墙阻碍；
- **方式二**：参照 **`20篇抽样代表性文献清单.md`** 中的 DOI 官方链接在线访问完整论文；
- 对每一篇文献，从 D0（纳排）到 D5 做出您的独立学术判定；
- 填入支撑您判断的章节号/公式号与简短引文。

### 步骤 3：保存并交付
完成 20 篇编码后，请将填写好的 CSV 文件直接保存并发送回项目负责人。项目组将通过独立后处理程序计算一致性并商定分歧仲裁。

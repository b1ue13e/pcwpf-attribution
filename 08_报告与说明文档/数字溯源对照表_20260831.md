## 3. 根因与修复方案

**根因**：项目经历了多轮抢救式修订（2月11日 → 3月1日 → 3月2日 → 3月7日 → 3月29日），每轮换了划分/脚本/检查点，而正文表格是手工拼装（`table2_robustness_data.csv` 无 run_id），旧数字残留在正文和新数字混排。

**修复方案（按序执行）**：

1. **冻结唯一 canonical 协议**：80/20 划分（用 `04_数据集/split_manifest_80_20.json`）+ 固定 seed 集合 {42,123,2025,3407,777} + 固定评估脚本版本。
2. **一次性重跑全矩阵**：六个主模型 + FG-MoE 三变体 × 全部 corruption 档位，全部在 80/20 下重新生成（interactive730 两卡空闲，估计 6–12 GPU 小时）。
3. **表格自动生成**：禁止手工拼表；每个 LaTeX 表格由脚本从带 run_id 的 CSV 直接生成，表下注明 run_id。
4. **删除/替换孤儿数字**：0.8518、0.0741%、0.0076%、tau_sweep 估计值表。
5. **Table 1 与实际划分对齐**：要么全部数字改到 80/20 重跑，要么 Table 1 改成真实划分（会削弱 test 集规模，建议前者）。

### 四大核心贡献及其证据链

   - 五维解耦：D1 参数来源（87.0% 解析物理规律）/ D2 施加阶段（50.0% 架构 / 45.7% 损失）/ D3 推理遥测（82.6% 无依赖）/ D4 代码保真 / D5 伤害与消融报告。
2. **C2 46 篇文献 Scoping 审计（45 同行评审 + 1 预印本 UniWind）**：
   - 0/46 (0.0%) 报告负面效应或追踪物理违规率；
   - 44/46 (95.7%) 无公开可获取代码；
   - 仅 23/46 (50.0%) 执行严格隔离物理约束消融（$\lambda=0$ vs $\lambda>0$），另外 23/46 (50.0%) 仅消融多层神经网络子模块，混淆模型表征容量与物理先验。
3. **C3 PCT 官方代码静态审计与负对照**：
   - 发现 PyTorch `F.kl_div(p.log(), q)` 实现实为 $\text{KL}(q \parallel p)$，计算反向 JS 散度而非论文声称的对称 JS 散度；
   - 代数推导严格证明其成对核张量数学等价于标准 2D 乘积核 KDE，作为关键负对照驳斥了早期所谓“边缘独立性失效”指控。
4. **C4 解耦理论 + 真实 Elexon BSC 30 分钟净额结算下的双刃剑实证**：
   - **理论基石（求真版）**：命题 1 证明连续 CDF 下精确超额运行风险为 $(r+1)\mathbb{E}_X[\int_{q_\tau}^{p} (F_{Y|X}(u) - \tau) du] \ge 0$；严格保留常数平移反例（$\Delta \mathcal{R}_{disp} \equiv 0$）与空间异方差反例（有偏预测器校准后风险反低于条件均值）。
   - **Kelmarsh（平坦地形、高信噪比）**：DLinear 校准后施加分布约束，单边短缺支出反增 **$+£932.56$ / (台·年)** (95% CI: $[+£648.20, +£1,236.74]$)，平衡机制净现金流分量亏损 **$-£3,264.86$ / (台·年)** ($[-£4,365.40, -£2,223.50]$)；
   - **Hill of Towie（复杂丘陵地形、低信噪比）**：DLinear 校准后施加分布约束，单边短缺支出减免 **$-£578.57$ / (台·年)** ($[-£834.86, -£367.51]$)，平衡机制净现金流分量增收 **$+£1,481.27$ / (台·年)** ($[+£802.29, +£2,203.32]$)；
   - **Penmanshiel（实测验证）**：校准后功率曲线约束（$0.09753$）与分布约束（$0.09804$）均优于无约束 DLinear（$0.09864$），但仍弱于非深度基线（Ridge $0.09744$，Persistence $0.09586$）；
   - **PatchTST（跨骨干敏感性）**：60 组实验重现指标与场站分化（Kelmarsh 净现金流下降 £1,365.12/(台·年)，Penmanshiel 节省 £790.51/(台·年)，Hill 净现金流反转变动 $-£568.68/(台·年)$），明确约束效应随骨干与指标发生变动。

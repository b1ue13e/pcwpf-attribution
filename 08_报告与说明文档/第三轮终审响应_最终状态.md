## 核验：joint_pdf 的真实数学形式

官方：
```python
def marginal_pdf(values, bins, a, ...):
    residuals = values - bins.unsqueeze(0).unsqueeze(0)
    kernel_values = torch.exp(-0.5 * (residuals/a).pow(2))   # (1, n_samples, n_bins)
def joint_pdf(kernel_values1, kernel_values2):
    joint_kernel_values = torch.matmul(kernel_values1.transpose(1,2), kernel_values2)
    # = (n_bins_p, n_samples) @ (n_samples, n_bins_w) = Σ_s φ(b_i;w_s)·φ(b_j;p_s)
```

结论：**配对样本求和的 2D product-kernel 联合密度**，与论文 standard 2D KDE
**数学等价**，不蕴含独立性。

**撤回**：所有"independence-joint / outer-product 破坏物理依赖 / 独立性假设"表述
（`PCT官方代码核查报告.md` §3.3 已修正）。

**保留的唯一静态差异**：`F.kl_div(p.log(), q)` 的方向与标准 JS 不同 →
**reverse-JS-type divergence**（不能笼统称"非规范 KL 破坏约束"）。

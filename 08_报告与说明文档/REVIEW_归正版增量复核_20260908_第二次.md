## 2. P0：当前所谓30分钟净额仍按错时段结算

`evaluate_dynamic_price.py` 使用 `e[:,0:3]` 和 `e[:,3:6]` 切成两个SP，并分别取 `prices[:,0]`、`prices[:,3]`。

但本项目时间戳是观测区间结束时刻。以首个测试起点为例：

| 预测目标结束时间 | 实际覆盖区间 | 应属SP起始时间 |
|---|---|---|
| 00:00 | 前日23:50—00:00 | 前日23:30 |
| 00:10 | 00:00—00:10 | 00:00 |
| 00:20 | 00:10—00:20 | 00:00 |
| 00:30 | 00:20—00:30 | 00:00 |
| 00:40 | 00:30—00:40 | 00:30 |
| 00:50 | 00:40—00:50 | 00:30 |

所以六个点实际横跨三个SP，不能硬切成两组三点。直接用当前 `core.starts` 与实际CSV检查：

- Hill of Towie：7599/7599个起报点，两组三点都跨真实SP；
- Kelmarsh：8212/8212，同样全部跨界；
- Penmanshiel：8440/8440，同样如此。

单边短缺指标受到错误净额与错误价格分配双重影响；带符号净现金流虽然对求和顺序线性，却仍受错误价格分配影响。因此新报告的£1310.24、−£3287.56、+£1533.49目前均不能作为已验证的真实结算结论。

修复方式：展开为带实际交付时间的长表，用 `(target_end−10min).floor('30min')` 作为SP键，在整段时间轴上汇总唯一交付记录。跨起报点的同一SP也要合并；边界/缺测造成的不完整SP单独标记或排除，并明确覆盖率。另一选择是重新定义与SP边界一致的起报/交付窗口，但要重新评估预测和校准，不能只改标签。

每个保留SP应有三条不重叠10分钟交付、同一价格且完整覆盖。还要核对申报签发时刻与实际市场时间规则；当前小时滚动预测只是预测实验，不自动等同真实可执行BSC申报。

## 3. P0：新增净现金流仍只是结算分量

当前定义：

N(p)=π_SP(Y_SP−p_SP)。

这是按假设申报量计算的不平衡结算净流入。在π>0时，只要降低p，该量就增加；即使预测更差也可能表现为“多赚钱”。它尚未包含因减少预售/合约申报而失去的收入。

若比较不同申报策略的完整经济性，最简双结算模型也需区分交易收入与不平衡结算，例如：

Π(p)=π_contract·p+π_imbalance·(Y−p)，

再说明交易价格、合约量、信息时序和风险约束。若只研究净不平衡现金流分量，就用这个精确名称，不称完整净利润、真实赚取或亏损。

标准化2:1情景损失与这一线性净现金流不是同一个目标。q=1/3校准并不自动最优化后者。加入双向现金流，不能据此把旧的分位数最优性结论移植过去。[Elexon市场与结算说明](https://bscdocs.elexon.co.uk/guidance-notes/the-electricity-trading-arrangements-a-beginners-guide)

## 4. Penmanshiel的新引用错误

### 场站规格

主线索引写30.75MW/15台，稿件还写MM92；实际准备数据的 `rated_kw` 为28700，发布方明确为14台Senvion MM82，且没有WT03。原静态表和准备manifest均支持28.7MW/14台。[官方数据说明](https://zenodo.org/records/5946808)

不能把文件编号WT01—15误当15台机组，也不能替换容量而不重算标幺指标。

### 数值与对照

当前 `analysis/summary.csv` 中，Penmanshiel、clean、ratio=2、quantile_calibrated、all：

| 方法 | 当前均值代价 |
|---|---:|
| 无约束DLinear | 0.098640 |
| 曲线约束 factor=1.0 | 0.097534 |
| 分布约束 factor=1.0 | 0.098044 |
| 分布约束 factor=0.9 | 0.097805 |
| 岭回归 | 0.097441 |
| Persistence | 0.095856 |

正文0.09780来自factor=0.9误设条件，不能无说明替代默认factor=1.0。曲线0.09696未在所声明同条件主行找到，需提供确切原始行，否则改回0.097534。

有利证据需要保留：默认曲线和分布约束相对无约束DLinear确有较低代价，当前区间表的三项比较调整区间均未跨零。但两者均值仍高于岭回归与Persistence。正确结论是“相对特定骨干有收益”，不是已经证明复杂地形需要物理护栏。

## 5. 机制仍是假说，不能从场站名称推断因果

新稿用“Kelmarsh高SNR平坦地形→约束有害；高地强湍流→约束防过拟合”解释分化。当前新增代码没有对应的SNR估计、统一湍流分层、同场景干预或跨站点统计模型。

几个站点同时在机型、训练样本量、季节、缺失率、价格暴露、校准误差上不同。站点结果不同不能确定是地形/SNR造成。Hill的某现金流分量改善也不能直接证明其物理表征更准确。

建议保持原始“场站依赖/指标依赖”的观察，地形与SNR作为待检验解释。若要机制证据：事先定义可测量的状态量，做站内分层或受控扰动，记录偏置、条件误差及校准残差，最后在未用于规则设计的数据上检验。

## 6. 理论与正文尚未同步收敛

白皮书的核心积分式与反例已修好，但摘要仍写“校准消除Term II”“暴露高SNR下表征扭曲”；主线仍声称“必须严格解耦”。这些强表述不是积分式的推论。

当Δτ(X)随X变化时，一个常数δ不能令δ−Δτ(X)处处为零。直接估计条件分位数也可能实现最优决策，并不逻辑上要求先估条件均值。

其他可修细节：

- 理论Y∈[0,1]与实际保留超铭牌观测不完全一致，应分清理论简化与实际数据；
- F连续可微不足以自动得到统一三阶O余项，可补密度局部Lipschitz/适当可积条件，或采用更弱余项；
- “机制假说”应保持假说口吻，不在摘要先写成已证实机制；
- 删去“法定、坚不可摧、100%闭合”等项目治理式措辞，外部审稿看证据与可复核性。

## 7. 文献材料修复不等于重新独立盲审已经完成

手册已移除待测答案、S10摘录已纠正，这是有效修复。但本地A/B/C原始填写表的时间仍在本次修复之前，新报告的κ也沿用旧编码数据。未找到基于净化后材料重新独立编码的新增原始表。

这些κ可以作为旧阶段的一致性记录，不能重新标成“修复后干净盲审的信度”。重新独立评估最好由未接触旧答案的编码者执行；已接触者复编须披露为修订后复评，不能倒称未暴露。

`calculate_cohen_kappa.py` 仍保留常数标签时赋κ=1的逻辑。新报告改为NaN，但自动生成链尚未同步，复跑仍会产生旧问题。

S10可以确认所查代数约束与代码相符；`code-aligned`应注明检查范围与版本，不自动等于整个实现或所有结果忠实复现。S10/S34静态功率建模是否属于主语料的时序forecasting范围，也仍需统一纳排定义。

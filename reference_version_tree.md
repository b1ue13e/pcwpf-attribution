# Bibliographic Reference Version Trees (Strict Work Manifestation Ontology)

> **Ontological Axiom & Hard Guardrail**:
> - A **Version Tree** may contain **ONLY** manifestations of the **SAME** intellectual work.
> - Permitted tree nodes: `PREPRINT`, `CONFERENCE VERSION`, `TECHNICAL REPORT`, `ACCEPTED MANUSCRIPT`, `REPUBLISHED VERSION`, and `VERSION OF RECORD` (VOR).
> - **Zero Tolerance for Lineage Contamination**: Any companion study, parallel paper, thematic follow-up, or methodology extension is strictly barred from the tree and relegated exclusively to the separate `Related Work Lineage` section (informational only, never labeled as a version).

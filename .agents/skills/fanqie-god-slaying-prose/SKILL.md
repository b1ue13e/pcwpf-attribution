# 番茄爆款暗黑弑神动作流写作规范 (Fanqie God-Slaying Prose SOP)

本 Skill 是《众神已死，只有我还在祷告》及同类暗黑神诡/弑神动作流小说的**正文写作与润色最高标准**。一旦进入正文撰写、战斗设计、对话打磨或章节重写，必须无条件执行本规范。

---

## 1. 核心文风三大爆款支柱

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 《我在精神病院学斩神》高燃分镜 ──> 暴烈神性、出鞘破空、电影感 │
│ 2. 《神秘复苏 / 道诡异仙》冷峻规则 ──> 冰冷代价、诡异压迫、绝不降智 │
│ 3. 《十方武圣》硬核物理打击感 ──> 重心变轨、骨肉撕裂、刀刀见血 │
└─────────────────────────────────────────────────────────────┘
```

1. **极简白描，拒绝修辞自嗨**：
   - 刀就是刀，血就是血，骨头断裂就是一声脆响。
   - **全面封杀刻意生硬的比喻**（严禁无脑使用“像……一样”）。用纯粹的动作、名词、环境白描推进画面。
2. **冷面杀胚与实用主义反差**：
   - 黎恩不是自怨自艾的衰小孩，也不是口嗨装逼犯，而是**无灯镇老怪养大的冷面技术流**。
   - 面对外界惊骇的高阶神蚀、狂傲的教廷骑士，黎恩以“砍柴/杀猪/正骨”的朴素逻辑对待，形成极具冲击力的**满级降维打击爽感与冷幽默**。
3. **出招即分生死的硬核动作流**：
   - 打斗绝不报招式名字、不搞光污染对轰，写**发力重心、步法变轨、剑刃入肉角度、肌肉拉扯与骨骼死穴**。
4. **接地气、带潜台词的自然对话**：
   - 台词简短干脆、直击要害，说话带生活糙感与潜台词。
   - 坚决杜绝“AI 翻译腔”、长篇说教与空洞升华。
5. **极速推进的高留存节奏**：
   - 每一段都在推动剧情、交代动作或造成实质伤亡，绝无纯风景描写与情绪水文。

---

## 2. 硬核动作流分镜写作法则 (Kinetic Combat)

在描写打斗与斩杀时，必须按照以下物理维度展开：

- **受力与重心**：写脚步蹬地、肩背发力、剑脊受力的微小形变；
- **解剖学弱点**：黎恩出剑永远奔着喉骨、关节缝隙、肌腱连接处等致死死穴；
- **声音与触感**：铁器擦出火星的尖啸、剑锋切开肌肉的钝感、鲜血溅在石板上的微温；
- **节奏快慢相间**：出招前压抑蓄力，出剑瞬间一击毙命，收剑后动作干脆利落。

## 3. 语言禁令与反 AI 模板库 (Prose Blacklist)

正文撰写时**绝对禁止**以下模式：

- [ ] **严禁破折号**：正文禁止使用中文破折号“——”进行停顿或解释，改用句号、逗号、动作换段。
- [ ] **严禁模板对比句**：“不是A而是B”、“不仅A更B”、“表面A实际B”（同一章内出现不超过1次）。
- [ ] **严禁空洞心理旁白**：“他意识到”、“他感到一股莫名的恐惧”、“这意味着”。
- [ ] **严禁生硬比喻**：杜绝“像随手扔在墙角的碎煤渣”、“像被水泡透的羊皮纸”等脱离场景的生硬联想。
- [ ] **严禁事后解释象征**：删掉“这代表着他终于释怀了”等说教句。

## 4. 单章黄金 3-Scene 结构 (2000—2400字)

- **Scene A (800字) 现实紧迫性切入**：
  从一个具体的异常物品、伤势或危机直接切入，人物迅速进入行动，杜绝冗长背景交代。
- **Scene B (800字) 冲突升级与硬核动作/反差碰撞**：
  敌人或神蚀压迫降临，黎恩以满级常识或冷峻身手正面迎击，完成一次极度利落的硬核兑现。
- **Scene C (600字) 规则代价与黄金钩子**：
  危机解决后留下不可逆变化（神债记账、伤痕、身份线索），章末抛出致命事实钩子，让读者欲罢不能。

## 5. 交付前自查闭环

每章写完后，必须执行：
1. 运行 `prose_lint.py` 扫描，达到 0 处违规；
2. 对照《连续性台账》当章【禁止泄露】清单，绝不超前剧透；
3. 输出自查结论清单随文交付。

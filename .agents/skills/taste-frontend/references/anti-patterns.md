# Anti-Slop 绝对禁忌黑名单 (The Blacklist)

本文件汇总了所有导致前端界面产生“廉价感”、“拼凑感”和“典型 AI 生成味”的禁忌反模式。**任何交付的代码若触发以下禁忌，均视为未通过质量门禁。**

---

## 1. 排版与字体禁忌 (Typography Tells)

| 禁忌现象 | 为何有害 | 正确替代方案 |
|---|---|---|
| **将 `Inter` 作为无脑默认无衬线字体** | 极度同质化，抹杀一切品牌性格 | 使用 `Geist`, `Outfit`, `Cabinet Grotesk`, `Satoshi`, `Plus Jakarta Sans` |
| **将 `Fraunces` / `Instrument Serif` 作为通用的 AI 默认衬线** | 烂大街的 AI “伪质感”指纹 | 严格按需选用 `PP Editorial New`, `Tiempos Headline`, `Playfair Display` 等 |
| **同一大标题内硬插一个不同字族的衬线单词** | 生硬拼接，极度业余 | 强调单词使用**同字族的斜体 (Italic) 或粗体 (Bold)** |
| **斜体展示大字时下行字母被裁剪** | 视觉 Bug，严重失准 | 必须使用 `leading-[1.1]` 并添加 `pb-1` 容器留白 |
| **正文段落过长无限制** | 严重降低可读性与浏览体验 | 严格使用 `max-w-[65ch]` 并在桌面端限制行宽 |
| **标题多处单词被动换行留下单字** | 版面支离破碎 | 使用 CSS `text-wrap: balance` 或 `text-wrap: pretty` |

## 2. 色彩与材质禁忌 (Color & Material Tells)

| 禁忌现象 | 为何有害 | 正确替代方案 |
|---|---|---|
| **AI 紫色/蓝色渐变发光 (Lila Glow)** | 典型 2023-2024 年廉价 AI SaaS 模版印记 | 纯净中性底（Zinc / Slate / Stone）+ 单点高反差强调色 |
| **无脑使用米黄纸色+黄铜色 (`#f5f1ea` + `#b08947`)** | 消费品/餐饮类 AI 生成的极度同质化套路 | 轮换使用冷冽金属灰、深林墨绿、纯黑白单点亮色或大地砖红 |
| **大面积使用纯死黑 `#000000`** | 缺乏空间深度与物理真实感 | 使用有色相倾向的微深灰 `#09090B`, `#0A0A0A`, `#121212` |
| **页面中途突兀翻转暗黑/明亮主题** | 破坏视觉连贯性，像拼凑页面 | 全页面锁定统一主题；若做主题切换必须有全局平滑过渡设计 |
| **同一组件树内混杂冷灰 (`slate`) 与暖灰 (`stone`)** | 色彩逻辑混乱，视觉脏乱 | 全局锁定单一中性灰阶基底 |

## 3. 布局与结构禁忌 (Layout Tells)

| 禁忌现象 | 为何有害 | 正确替代方案 |
|---|---|---|
| **全站一律使用居中 Hero + 居中标题** | 呆板平庸，缺乏现代设计张力 | 采用 50/50 左右分栏、左文右图或非对称留白 |
| **每个 Section 上方都放一个小大写 Eyebrow 标签** | 机械重复，最严重的 AI 结构套路 | **每 3 个区块最多允许 1 个 Eyebrow**，其余靠大标题与位置自解释 |
| **固定的 3 列等宽白底卡片并排** | 最常见的 Bootstrap/AI 默认卡片套路 | 2 列交错布局、Bento 非对称网格、水平滑动或全宽重点呈现 |
| **左右交替图文连续出现 ≥3 次** | 机械单调的“Z 字折叠” | 连续图文最多 2 次，第 3 次必须打破（换全宽、Bento 或列表） |
| **全屏使用 `h-screen`** | 移动端 Safari 地址栏伸缩时引发剧烈视口跳动 | 必须使用 `min-h-[100dvh]` |
| **用 Div 拼凑假的界面截图 / 控制台** | 塑料感严重，经不起推敲 | 使用真实生图素材、真实 SVG 图标或可交互的真实 mini 组件 |

## 4. 文案与数据禁忌 (Copy & Data Tells)

严禁在文案中生成假大空的 AI 陈词滥调与虚假精密数据：

### 🚫 严禁的 AI 浮夸词汇：
- 英文：`Elevate`, `Seamless`, `Unleash`, `Next-Gen`, `Game-changer`, `Delve`, `Tapestry`, `In the realm of...`, `Empower`
- 中文：`赋能`, `颠覆性`, `一站式无缝融合`, `重塑新范式`, `开启下一代体验`, `探索...的无限可能`

### 🚫 严禁的虚假假精确数据：
- 严禁凭空捏造 `99.99%`, `48.7k+`, `4.1x 吞吐量` 这种假装专业的数字。若非真实业务数据，必须标注示例或使用真实具体的上下文表达。

## 5. 代码实现与输出禁忌 (Code Output Tells)

1. **绝对禁止偷懒代码占位符**：
   - 严禁输出 `// TODO: add more cards`
   - 严禁输出 `// ... rest of implementation`
   - 严禁输出 `/* same as above */`
   - 必须交付 100% 完整、闭合、可直接执行的前端源码。
2. **严禁在滚动事件中更新 React State**：
   - 严禁 `window.addEventListener('scroll', () => setY(...))`。
3. **严禁对引起重排的属性做动画**：
   - 严禁对 `top`, `left`, `width`, `height`, `margin` 进行 transition/animation，仅对 `transform` 和 `opacity` 进行硬件加速过渡。

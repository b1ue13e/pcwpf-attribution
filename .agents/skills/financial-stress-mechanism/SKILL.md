# Financial Stress Mechanism

## Core Hypothesis

Treat the project mainline as an executable hypothesis, not a proven conclusion:

> Physical/engineering source-domain pretraining learns temporal stress descriptors that can transfer, under identifiable market and regime conditions, to financial drawdown-stress monitoring.

The skill's job is to help turn this hypothesis into evidence. Never write it as established fact unless the required controls and external validations pass.

## Default Position

Start from a skeptical `Conditional Go`:

- Internal CSI300 gains support an HGB-anchored auxiliary rank-fusion workflow.
- External locked-transfer failures on CSI500/SSE50 must be treated as evidence against broad frozen transfer.
- Mechanism language requires intervention or counterfactual evidence, not only AP gains or rank movement.
- Reproducibility is part of the experiment.

## Workflow

1. **Claim gate**
   - Identify whether the requested output assumes broad transfer, market-conditioned transfer, or CSI300-specific rank fusion.
   - Downgrade broad transfer language unless external and mechanism evidence support it.

2. **Evidence map**
   - Map each claim to current evidence, missing evidence, likely reviewer attack, and decisive response.
   - Keep external non-confirmation visible.

3. **Experiment design**
   - Prefer decisive controls over more benchmark tables.
   - Prioritize formal negative controls, mechanism interventions, external failure decomposition, and market-adapted validation.

4. **Reviewer-risk audit**
   - Attack source-mechanism claims as post hoc until shuffled-source, unrelated-source, phase-randomized-source, label-shuffle, and time-shift controls are complete.
   - Attack transfer claims if CSI500/SSE50 locked validation remains negative.

5. **Reproducibility closure**
   - Require manifest, environment lock, raw predictions, table/figure source data, checksums, and one-command reproduction path.

## Claim Ladder

Use the strongest claim whose gate is satisfied:

| Level | Claim | Required evidence |
|---|---|---|
| L0 | Auditable CSI300 rank-fusion workflow | Strict CSI300 result, random control, leakage audit |
| L1 | Source-pretrained auxiliary signal | Real-source beats random, shuffled-source, unrelated-source, and label/time controls |
| L2 | Market-conditioned transfer | Validation-year-only market-adapted rule beats external HGB anchor |
| L3 | Candidate transferable mechanism | Mechanism perturbations/counterfactuals show directional response |
| L4 | Broad transferable mechanism | Multiple external market families and mechanism tests pass without post-hoc selection |

If a gate fails, state the downgrade explicitly.

## Must-Ask Checks

Before supporting the mainline, check:

- Did the result beat HGB anchor, not only a weak validation-selected baseline?
- Did it beat matched random fusion?
- Did formal label-shuffle and time-shifted source-encoder controls collapse?
- Did shuffled-source and unrelated-source controls fail to match real-source?
- Did external locked transfer pass, fail, or require market adaptation?
- Are q, alpha, source mix, and label budget chosen by a legitimate validation rule?
- Can every table/figure be regenerated from manifest-tracked artifacts?

## Experiment Priorities

Fatal:

- Formal source-encoder label-shuffle and time-shifted controls.
- Formal shuffled-source and unrelated-source controls.
- Phase-randomized source control.
- External failure decomposition for CSI300 vs CSI500/SSE50.
- Market-adapted validation with validation-year-only selection.

High priority:

- Volatility-scale, persistence, frequency-band, and drawdown-path interventions.
- Regime-conditioned transfer map.
- Strong contemporary financial/time-series baselines.
- Discovery-path and multiple-comparison accounting.

Reproducibility:

- `artifact_manifest.csv`
- `requirements-lock.txt` or `environment.yml`
- `reproduce_main_tables.ps1`
- `reproduce_cross_market_audit.ps1`
- `reproduce_negative_controls.ps1`
- `checksums.sha256`
- Data/code/model availability statements.

# General Paper Skill

## Core Rule

把论文当作“可被审稿人追问的证据链”，不是把文字润色得更顺。每次使用本 skill，都先检查问题意识、研究设计、证据、结论边界和文献可靠性，再动笔改写。

严禁虚构数据、显著性、样本统计、稳健性结果、文献、DOI、期刊信息或政策事实。缺证据时，用保守表述或列为待补材料。

## Positioning

本 skill 是从 Nature-style skills 的科研流程思想本地化而来，但目标不是模仿 Nature 文风。用于中文核心、CSSCI/北核风格、普刊、学位论文、课程论文升级投稿和一般英文/中文实证论文。

对一般中文经管论文，优先使用以下口径：

1. 问题意识先于模型名。
2. 变量与样本口径先于结果解释。
3. 相关关系不写成因果效应。
4. 复杂模型必须服务于识别异质性、机制解释或预测任务。
5. 贡献写成“推进了哪一处具体争议或方法缺口”，不要写空泛的理论和实践意义。

## Default Workflow

1. **任务定位**
   - 判断目标：投稿版、课程版、学位论文、开题、摘要、引言、结果解释、整稿降 AI 味、审稿风险诊断。
   - 判断学科：经管、信息管理、计算机、社会科学、教育、医学、工程等。
   - 判断证据类型：实证、方法、综述、案例、政策分析、理论文章。

2. **建立事实底座**
   - 提取题目、研究问题、数据来源、样本期、变量、模型、主要结果、局限。
   - 标出不可改写成事实的内容：未跑出的结果、未核验文献、仅为设计方案的部分。

3. **审稿人风险诊断**
   - 问题是否是真问题，而不是“把 A 和 B 融合一下”。
   - 文献综述是否呈现争议，而不是作者清单。
   - 数据与标签是否可追溯，是否有泄漏、幸存者偏差、样本选择问题。
   - 模型是否与问题匹配，是否有强基线和消融。
   - 结果解释是否越过识别能力。
   - 贡献是否可被一句话反驳。

4. **改写顺序**
   - 先改标题、摘要和引言的核心论证。
   - 再改文献综述与研究假设，使其服务于研究问题。
   - 再改研究设计，使变量、模型、样本筛选和泄漏控制可复核。
   - 再改实证结果，区分“显著相关”“预测有效”“机制解释”“局限”。
   - 最后改结论，写发现、边界和下一步，而不是复述全文。

5. **输出检查**
   - 若产出 DOCX，必须结合 Documents skill 渲染检查。
   - 若引用外部文献或近期事实，必须核验来源。
   - 若用户要求“直接改论文”，保留原稿，另存优化版。

## Section Rules

### 摘要

用“问题—方法—数据—发现—贡献—边界”结构。避免“本文具有重要意义”“提供参考”等空话。摘要中出现的数字必须来自实际结果。

### 引言

第一段写现实或理论痛点，第二段写现有方法为什么不够，第三段写本文如何回答，第四段写贡献。不要从宏观背景一路铺陈到模型。

### 文献综述

把文献写成争议链：

- 早期研究解决了什么。
- 后续研究改进了什么。
- 仍然留下什么测量、样本、识别、解释或方法缺口。
- 本文站在哪个缺口上。

### 研究设计

清楚报告数据来源、样本筛选、变量定义、标签构造、训练/测试切分、泄漏控制、模型设定和评价指标。机器学习论文必须解释为什么 Accuracy 不是低频风险任务的主指标。

### 实证结果

先报告描述事实，再报告统计检验，再报告模型结果，再报告解释性或稳健性。不要把预测模型写成因果识别。不要把所有模型都解释成“显著提升”。

### 结论

结论必须回答研究问题，写出边界条件。不要只重复“本文构建模型、进行实证、得出结论”。

## Style Rules For Chinese Papers

- 删减默认套话：“值得注意的是”“需要指出的是”“基于此”“有鉴于此”“从理论和实践层面看”“具有重要意义”。
- 避免过度平滑：失败、限制、未超过基线的结果要如实写。
- 保留必要谨慎：观察性数据写“相关”“区分能力”“预测表现”，不用“导致”“促进”“影响机制已经证明”。
- 句子尽量短，核心判断放前面。
- 贡献写具体：例如“把属性分析结果从特征筛选推进到路由约束”，而不是“丰富了相关研究”。

## Reviewer Risk Checklist

交付前逐项检查：

- 研究问题是否能用一句话说清。
- 样本和标签是否可追溯。
- 是否报告剔除样本和原因。
- 是否有统计基准与机器学习强基线。
- 是否解释类别不平衡。
- 是否避免标签泄漏。
- 是否把复杂模型定位为扩展而非炫技。
- 文献是否真实且表述准确。
- 结论是否没有超过数据支持。

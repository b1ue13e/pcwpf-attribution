# 第二轮：强简单骨干与统一决策校准

本轮核心骨干为真正的单变量 DLinear（移动平均分解＋季节/趋势线性映射），外加同输入信息条件下的岭回归与 Persistence。DLinear 使用与第一轮相同的三类训练约束函数，保持初始化、训练预算、λ 网格和误设幅度一致。原三个场站测试属于探索性复用；Hill of Towie 2017 是本轮新外部验证。

1. `download_hill.py` 下载官方元数据和2016/2017压缩包，以官方MD5验证后才原子重命名。
2. `prepare_hill.py` 根据字典连接实测功率/风速与21台机组ID，只产生完整机组集合的整场目标。月边界重复必须全部字段一致。风速传感器差值统计只用训练期。
3. `core.py --site ... --backbone dlinear --seed ... --data ... --out ...` 训练候选。首段验证集选参/早停，后段验证集完全隔离用于校准。
4. 合并开发场站的 `validation_trials.csv` 后，`assess.py --lock --root ... --data ...` 冻结λ与岭回归α。外部站点不搜索λ/α，仅依固定规则早停。
5. `assess.py --site ... --root ... --data ...` 在第二段验证数据上计算残差分位数偏置，随后统一评估原始裁剪策略和校准策略。偏差代价为每小时更新的下一小时预测，价格比1/2/5；主指标为ratio=2。不是实际货币收益。
6. `summarize.py ROOT` 汇总，并对主要约束对照做训练seed＋完整日历7天块配对bootstrap（2000次）。新站点三项约束比较使用Bonferroni兼容区间，旧站点结果只作探索性证据。

远端运行目录：`/root/paper1/constraint_round2`。25329保存Kelmarsh/Hill of Towie，25979保存Penmanshiel/SMARTEOLE。本地数据、代码、权重和指标均有独立第二轮目录，不覆盖第一轮。

`core.py` 是第一轮受控核心的独立副本，新增DLinear及验证校准分割。它不是新的预测架构贡献。不能将“某个弱骨干相对改善”或“未经校准的代价下降”写成全面优越性。

复跑时采用新的输出目录，避免把不同代码/协议版本的断点混合。模型权重、代码哈希、原始数据哈希、选择锁与核查样例应共同保存。
